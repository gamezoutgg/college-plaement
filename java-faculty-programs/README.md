# Java Faculty Programs

Runnable Java examples based on the faculty-provided snippets. Each example is in its own class and uses the package `com.college.placement.javafundamentals`.

## Run in Eclipse or VS Code

1. Open the `java-faculty-programs` folder as a Java project.
2. Mark `src` as the source folder if your editor does not do this automatically.
3. Run any class that contains a `main` method.

From a terminal in this folder, you can also compile and run all examples:

```powershell
javac -d out src\com\college\placement\javafundamentals\*.java
java -cp out com.college.placement.javafundamentals.MethodOverloadingDemo
```

## Programs

- `MethodOverloadingDemo` — overloaded `m1` methods.
- `MinBalanceOverloadingDemo` — overloaded `minbal` methods.
- `MethodOverridingDemo` — inheritance and method overriding.
- `InstanceVariableDemo` — an instance variable used inside a method.
- `AdditionDemo` — adding instance values and method arguments.
